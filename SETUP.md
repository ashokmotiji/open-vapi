# Open-Vapi Setup Guide

## 1. Clone the repo
```bash
git clone https://github.com/ashokmotiji/open-vapi.git
cd open-vapi
```

## 2. Set up environment
Copy `.env.example` to `.env` and fill the values.

## 3. Run locally
- Install Ollama and pull a model: `ollama pull llama3.1`
- `docker compose up`
